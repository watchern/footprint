# 本地足迹（Local Footprints）

复刻「灵敢足迹」核心功能的**完全本地化**安卓应用。无注册、无登录、无云端、无好友共享，所有数据只存在设备本地。

当前版本：**v1.3.1**（更新日志见 [CHANGELOG.md](CHANGELOG.md)）

## 功能

- **我的足迹**：地图上按出行方式着色显示全部历史轨迹，支持一键全览
  - 底部直接选择出行方式并**一键开始记录**，记录中实时显示时长与里程
  - **左下角比例尺**：随缩放自动更新，显示当前比例尺读数（m / km）
  - **右下角定位按钮**：一键定位到当前位置，并将比例尺缩放到 **500 米**
  - **当前位置方向标**：带方向箭头与精度圈，箭头指示设备朝向
- **运动记录**：步行 / 跑步 / 骑行 / 驾车，实时统计距离、时长、均速、最高速
- **时间轴**：按天分组的出行历史，点击查看单次轨迹详情与回放
- **我的**：累计里程/时长/次数/天数、本地账号 ID、隐私说明
- **底图与离线地图**：底图源可插拔切换、自定义镜像地址、导入 MBTiles 离线包

## 隐私设计

| 数据 | 存储位置 | 是否联网 |
|---|---|---|
| 轨迹点 / 运动记录 | 本地 SQLite（`footprints.db`） | 否 |
| 本地账号 ID | 本地 SQLite（UUID 自动生成） | 否 |
| 收藏 / 设置 / 离线包索引 | 本地 SQLite | 否 |
| 照片、位置信息 | 不采集 | 否 |

应用**没有注册、没有登录、没有服务器、没有云端备份、没有好友/社区功能**。卸载应用或清除数据将永久删除全部足迹。

地图底图仅用于渲染显示瓦片，请求中不包含任何个人信息。

## 坐标系设计（重要）

轨迹在数据库中**始终以 GPS 原始坐标 WGS-84 保存**，坐标转换只发生在渲染层：

- 高德 / 腾讯地图使用 **GCJ-02**（国测局加密坐标）→ 渲染时做 WGS-84 → GCJ-02 纠偏
- 天地图 / OSM 使用 **WGS-84** → 直接使用原始坐标

因此切换底图源**不会造成轨迹偏移**，也无需迁移任何历史数据。

## 比例尺与定位

比例尺基于 Web Mercator 公式实时计算：

```
米/像素 = 156543.03392804097 × cos(纬度) / 2^zoom
```

「定位到当前位置」按钮通过**反解**该公式得到目标缩放级别，
使比例尺读数恰好为 500 米（在不同纬度下均成立，已由单元测试覆盖）。

## 朝向箭头

箭头方向采用**双来源**策略：

1. **罗盘**（磁力计）——设备朝向，静止时依然有效
2. **GPS 航向**（course over ground）——移动方向，无罗盘设备回退使用

注意：`geolocator` 的 `heading` 字段实际是「对地航向」而非罗盘朝向，
静止时无意义，因此不能单独用于方向箭头。

## 底图源

所有源统一使用 XYZ 瓦片协议（`{z}/{x}/{y}`），这也是 OSM 的事实标准，天地图、高德、腾讯均可映射到该协议，便于未来替换为任意合规源。

内置源：

| 源 | 坐标系 | Key | 说明 |
|---|---|---|---|
| 高德矢量 | GCJ-02 | 不需要 | 默认，国内直连流畅 |
| 高德卫星影像 | GCJ-02 | 不需要 | 卫星图 + 路网标注 |
| 天地图 | WGS-84 | 需要 | 需自行到天地图开放平台申请 |
| OpenStreetMap | WGS-84 | 不需要 | 国内访问不稳定，建议改用镜像 |

**自定义镜像**：在「底图与离线地图」中可填写任意 XYZ 模板，例如
`https://tile.openstreetmap.de/{z}/{x}/{y}.png`。

**离线地图包**：支持导入标准 `.mbtiles` 文件（MBTiles 规范），断网也能查看底图。离线包可从地图下载工具或镜像站点获取。

## 构建

> 本项目**不在本地构建**，统一由 GitHub Actions 构建并发布。

```bash
flutter pub get
flutter test              # 单元测试：坐标纠偏、距离计算、瓦片行号翻转、定位新鲜度
```

推送 `main` 后 CI 自动运行测试并构建 APK，产物在 Actions 的 Artifacts 中；
推送 `v*` 标签则额外创建 GitHub Release 并附带 APK：

```bash
git tag v1.0.1 && git push origin v1.0.1
```

Release 地址：https://github.com/watchern/footprint/releases

## 版本号约定

每次改动递增版本号（`pubspec.yaml` 的 `version: x.y.z+build`）：
功能修复/小改进 → 补丁号（1.0.1 → 1.0.2），新增功能 → 次版本号（1.0.2 → 1.1.0）。
